# 間柱・耐風梁・水平ブレースリスト作図ツール

SS7構造図作成ツール（draw.py / memberlist2.py）の補助。鉄骨部材リストの
「小梁・間柱・その他」表と同じ書式で、間柱・耐風梁・水平ブレースの3つのリストを
DXF（R12, cp932）と PDF に書き出す。

## 使い方

```
python sub_member_list.py <入力.json> <出力.dxf> <出力.pdf> [--scale 50]
```

- 必要なライブラリは matplotlib だけ（ezdxf 不要）。
- 寸法は紙上 mm（A1 想定、文字高 2.5）。`--scale 50` を付けると DXF の座標を 50 倍にするので、
  1/50 の図面のモデル空間にそのまま置ける。PDF は常に紙上寸法。
- 日本語フォントは Noto Sans CJK JP → IPAGothic の順に探す。
- 図枠・表題欄は付けない。
- 画層: `LIST_LINE`（罫線, 色7）、`LIST_TEXT`（文字, 色7）、`LIST_TITLE`（表名・特記, オレンジ40）。

サンプル:

```
python sub_member_list.py sub_member_list.sample.json out.dxf out.pdf
```

## 入力 JSON の書式

```json
{
  "title": "間柱・耐風梁・水平ブレースリスト",
  "tables": [
    {"name": "間柱リスト",         "rows": [ {...}, ... ]},
    {"name": "耐風梁リスト",       "rows": [ ... ]},
    {"name": "水平ブレースリスト", "rows": [ ... ]}
  ],
  "notes": ["特記事項1", "特記事項2"]
}
```

行のキー（列は参考図「小梁・間柱・その他」と同じ順）:

| キー | 列 | 例 |
|---|---|---|
| sym | 符号 | P12 / HB1 / HV1 |
| sec | 部材 | H-125×125×6×8 / JISブレース（TB付） 1-M16 |
| mat | 鋼種 | SS400 / SNR400B |
| bolt | 接合部 nw×mw-HTB | 1×2-M20 |
| nP | ピッチ nP | 70 |
| mP | ピッチ mP | 70 |
| gpl | G.PL 板厚 | 9 |
| e | G.PL e | 40 |
| type | 接合部 TYPE（凡例 a〜d） | c |
| rem | 備考 | 間柱 / 羽子板 FB-6.0×50 HTB 1-M16 G.PL-9 |

空欄や未記入のキーは「-」で出る（符号・部材・鋼種・備考は空白）。

## 記入の決まり

- 符号は参考図に合わせる。間柱 P＋梁せい（P12, P17）、耐風梁 HB＋番号、水平ブレース HV＋番号。
- 間柱・耐風梁は SS7 の構造モデルに含まれない。断面・接合部は意匠図と 2次部材の計算書から記入し、
  ユーザーに確認する。
- 水平ブレースは SS7 にデータがあれば符号・断面・鋼種を転記する。羽子板・G.PL・HTB は
  データにないので空欄にして確認する。SS7 にデータがなければ特記に「部材は別途」と書く。
- 接合部 TYPE は鉄骨部材リストの「小梁・耐風梁・間柱横接合部 凡例」TYPE-a〜d を参照する
  （凡例図はこのツールでは描かない）。
- 間柱の柱脚が溶接なら接合部欄は「-」にし、備考に「柱脚部溶接」と書く。

## SKILL.md への追記案（ss7-kateidanmen-drawings）

「3. 作図の決まり ＞ 部材リスト」の末尾に次を足す。

```
- 鉄骨部材リストの下（または右）に、間柱リスト・耐風梁リスト・水平ブレースリストを
  「小梁・間柱・その他」と同じ列（符号・部材・鋼種・nw×mw-HTB・ピッチnP/mP・G.PL板厚/e・TYPE・備考）で並べる。
  作図は tools/ss7/sub_member_list.py（入力は JSON）。
  間柱・耐風梁は SS7 にないので断面はユーザー支給の値を入れ、水平ブレースは SS7 の値を使う。
  羽子板・G.PL・ボルト本数など SS7 にない項目は空欄にして確認する。
```

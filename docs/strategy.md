# YouTubeチャンネル 収益化方針書

作成日: 2026-11-07
ステータス: ドラフト（ユーザー判断が必要な項目は「要決定」と記載）

---

## 1. ゴールと期限

| 目標 | 数値 | 期限 |
|---|---|---|
| 第1目標（現行基準で申請） | 登録者1,000人 ＋ 長尺の視聴時間4,000時間 | 2027年1月31日 |
| 第2目標（新基準で申請） | 登録者1,000人 ＋ 長尺の視聴時間8,000時間（365日） | 2027年6月末 |
| ショート収益の副目標 | ショート再生 過去90日で1,000万回 | 狙わない（導線としてのみ使う） |

- 2027年2月1日から新規参加の条件が倍（8,000時間 / 2,000万回）になる。1月末までの申請が最優先。
- ただしゼロから3か月弱で4,000時間は難度が高い。間に合わなくても止めず、第2目標に切り替える。
- ショート再生は視聴時間に加算されないため、視聴時間は長尺のみで稼ぐ。

### 4,000時間の逆算

4,000時間 = 240,000分。

| フォーマット | 尺 | 想定平均視聴率 | 1再生あたり視聴時間 | 必要再生数（単独で達成する場合） |
|---|---|---|---|---|
| 通常回 | 20分 | 40% | 8分 | 30,000回 |
| 総集編 | 90分 | 35% | 31分 | 7,700回 |
| 睡眠用・作業用 | 180分 | 30% | 54分 | 4,400回 |

結論: 通常回で認知と登録者を取り、総集編・長時間版で視聴時間を積む「二段構え」にする。

## 2. ジャンルとコンセプト

### 採用ジャンル: 歴史・事件・ミステリーの長尺ナレーション解説

選定理由:
- 日本で需要が証明済み（ゆっくり解説・ナレーション解説の定番ジャンル）。
- 事実の「解説」であり「助言」ではないため、AI人格による助言を禁じる2026年7月の不正コンテンツポリシーに抵触しにくい。
- ネタが尽きず、古い動画も再生され続ける（バックカタログが視聴時間を生む）。
- 視聴者層が広く、広告単価は中〜高。
- Claude Codeの強み（調査・台本・構成）を最大限使える。

不採用ジャンル:
- お金・投資・健康・法律・政治: AI人格の助言は収益化対象外。単価が高くても避ける。
- 海外の反応・2chまとめ・切り抜き: 他者コンテンツの流用で不正コンテンツ扱いのリスク。

### チャンネルの切り口（要決定）

同ジャンル内で競合と差をつける「切り口」を1つに絞る。候補:

| 案 | 切り口 | 強み | 弱み |
|---|---|---|---|
| A | 世界の未解決事件・失踪事件を「一次資料ベースで検証」 | 高い没入感、総集編・睡眠用と相性が良い | 実在の人物を扱うため名誉・センシティブ配慮が必要 |
| B | 歴史の「通説が覆った瞬間」（最新研究で変わった歴史） | 独自性が出しやすい、教育価値が高く広告向き | ネタ探しに調査コストがかかる |
| C | 世界史の「もしも」と「なぜ」（因果で語る世界史） | 評論的で量産テンプレと差別化しやすい | 視聴者が「正解」を求めやすく議論を呼ぶ |

推奨: A を主軸にBをサブシリーズとして混ぜる。Aは視聴時間、Bは登録者と広告単価に効く。

### 差別化の核（不正コンテンツ対策を兼ねる）

1. すべての動画に出典リストを概要欄に明記する（Wikipedia・公文書・報道・論文）。
2. 「断定しない。複数の説を並べ、どこまでが事実でどこからが推測かを明示する」を語りのルールにする。
3. 構成パターンを3種類以上持ち、同じ型を連続させない（テンプレ量産と判定されないため）。
4. 毎回「このチャンネルの見解」を1段落入れ、人間の視点があることを示す。

## 3. 言語（要決定）

| 選択肢 | 広告単価 | 競合 | 制作難度 |
|---|---|---|---|
| 日本語 | 中（目安 RPM 200〜500円） | 中 | 低（運営者が内容を確認できる） |
| 英語 | 高（目安 RPM 日本語の3〜8倍） | 非常に高 | 中（ネイティブ水準の台本と音声が必要） |

推奨: まず日本語で始める。運営者自身が台本の良し悪しとコメント対応を判断できることが初期の品質に直結する。英語展開は収益化後に同じパイプラインで横展開する。

## 4. フォーマット設計

| 種別 | 尺 | 頻度 | 役割 |
|---|---|---|---|
| 通常回 | 15〜25分 | 週3本 | 登録者獲得・ブラウジング流入 |
| 総集編 | 60〜120分 | 月2本 | 視聴時間の主力 |
| 睡眠用・作業用（通常回の再編集） | 120〜180分 | 月1本 | 視聴時間の上積み |
| ショート | 30〜59秒 | 毎日1本 | 登録者導線（長尺の切り出し＋独自ネタ） |

制作ルール:
- 冒頭30秒で「何が起きたか」と「なぜ未解決なのか」を提示し、離脱を防ぐ。
- 5〜7分ごとに「次の謎」を提示するチャプター構成にする。
- 終盤で次の動画を口頭で誘導し、終了画面で関連動画を出す。
- 総集編は単純連結ではなく、テーマで括り直し、つなぎのナレーションを新規に入れる。

## 5. 制作パイプライン（Claude Codeが自動化する部分）

```
ネタ選定 → リサーチ（出典収集） → 台本生成 → ファクトチェック → 読み上げ原稿整形
  → 音声合成（TTS） → 画像生成・素材収集 → 字幕生成 → ffmpegで動画合成
  → サムネイル生成 → タイトル・概要欄・タグ生成 → アップロード（API or 手動）
```

### 使用ツールと方針

| 工程 | ツール | 備考 |
|---|---|---|
| 台本・リサーチ | Claude Code | 出典URLを必ず台本に添える |
| ファクトチェック | Claude Code（別プロセス） | 台本とは独立した工程で、固有名詞・日付・数値を出典と突合 |
| 音声合成 | VOICEVOX（第一候補） | 商用利用可。動画内または概要欄に「VOICEVOX:キャラ名」の表記が必須。キャラごとの規約を確認する |
| 音声合成（代替） | ElevenLabs 等の有料TTS | 商用権が明確。予算があれば自然さで優位 |
| 音声合成（不採用） | edge-tts | Microsoft側サービスの商用利用条件が不明確。収益化動画には使わない |
| 画像 | Canva画像生成 / Pillowで自作図解 / Wikimedia Commons（パブリックドメイン・CC） | ライセンスを素材ごとに記録する |
| BGM・効果音 | YouTubeオーディオライブラリ、DOVA-SYNDROME 等 | 規約を確認し、必要なら表記 |
| 動画合成 | ffmpeg + Python | この環境で動作確認済み |
| 字幕 | 台本からSRT生成 → 焼き込み | 聞き流し視聴にも対応 |
| サムネ | Pillow / Canva | 文字は大きく3語以内、顔なしでも成立する構図 |
| 投稿 | YouTube Data API（要決定）または手動 | APIは申請と割当が必要。初期は手動でも可 |

### AI利用の開示

- 合成音声ナレーションと生成画像を使うため、YouTube Studioの「改変・合成コンテンツ」の開示設定は正直に行う。
- 実在人物の顔や声を模倣する生成は一切行わない。

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| 不正コンテンツ判定（テンプレ量産） | 構成パターン複数、独自見解の明示、出典明記、週3本を上限にして質を優先 |
| 事実誤認による信頼低下・通報 | 独立したファクトチェック工程、断定回避、訂正は概要欄とコメント固定で即対応 |
| 実在人物に関する名誉毀損 | 失踪・事件は公的に報道された情報のみ、被害者・遺族への配慮、推測を事実のように語らない |
| 音声・画像・BGMのライセンス違反 | 素材ごとに出典とライセンスを記録し、表記義務を自動で概要欄に挿入 |
| 著作権侵害の申し立て | 報道映像・他者動画は使わない。画像は生成・自作・パブリックドメインのみ |
| 収益化条件の改定 | 2027年1月末までの申請を最優先、間に合わない前提の第2目標も設定済み |
| 伸び悩み | 2週間ごとにKPIを見て、サムネ・冒頭・ネタの順に仮説検証。3か月で反応がなければ切り口を変更 |

## 10. 要決定事項（ユーザー）

1. チャンネルの切り口: A / B / C、または組み合わせ（推奨: A主軸 + Bサブ）
2. 言語: 日本語 / 英語（推奨: 日本語で開始）
3. 音声: VOICEVOXのキャラ（落ち着いたナレーション系か、ずんだもん等のキャラ系か）、または有料TTSの予算
4. 投稿方法: YouTube Data APIを使う（要API申請）か、初期は手動投稿か
5. 予算: 完全無料で始めるか、月数千円（有料TTS・画像生成）を許容するか
6. チャンネル名の候補（Claude Codeが10案出す → ユーザーが選ぶ）

決まり次第、フェーズ0（制作パイプラインの実装とテスト動画）に着手する。
